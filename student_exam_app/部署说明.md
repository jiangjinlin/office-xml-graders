# 考试系统部署说明

## 本机跑起来

```
cd student_exam_app
pip install -r requirements.txt
python app.py
```

默认 5000 端口，浏览器打开 http://127.0.0.1:5000 。题目从 `materials/<科目>/<题号>/3题干.docx` 读，素材从同目录下载。

## 上线（Linux + 宝塔）

第一次先把 `deploy.json` 填对：

| 字段 | 说明 |
|------|------|
| host | 形如 `root@1.2.3.4` |
| ssh_port / ssh_key | SSH 端口和私钥路径 |
| remote_dir | 项目在服务器上的绝对路径，比如 `/www/wwwroot/exam`；留空则按 `remote_hint` 自动搜 |
| app_port | 服务实际监听端口，探活用 |
| install_deps | 依赖有变化时设 true |
| pip_cmd | 服务器上装依赖的命令，宝塔要写成对应虚拟环境的 pip |
| reload_cmd | 重启方式，默认 `touch wsgi.py`（uwsgi --touch-reload） |

然后：

```
python deploy.py --dry-run     # 只预检和打包，不碰服务器
python deploy.py               # 真部署
```

流程是本地跑一遍回归测试 → 打包 → scp 到 /tmp → 服务器先备份到 `../exam_backups`（保留最近 5 份）→ 解包 → 重启 → 请求 `/api/health` 探活。

预检不过会直接中止，不会传到线上。

`reload_cmd` 用的是 uwsgi 停止再启动，不是 `touch`：

```
/www/server/pyporject_evn/xiaoshizi/bin/uwsgi --stop /www/wwwroot/student_exam_app/uwsgi.pid || true;
sleep 2;
/www/server/pyporject_evn/xiaoshizi/bin/uwsgi --ini /www/wwwroot/student_exam_app/uwsgi.ini
```

## 服务器端要求

- Python 3.8+（线上是 3.14）
- `pip install flask`
- 目录可写（`uploads/` 放临时上传，判分完自动清理）
- 注意：uwsgi 的 `sys.executable` 是 uwsgi 本身，`app.py` 会取同目录的 `python` 来跑评分器，也可以用 `EXAM_PYTHON` 指定

## 环境变量

| 变量 | 默认 | 说明 |
|------|------|------|
| EXAM_PORT | 5000 | 监听端口 |
| EXAM_MAX_UPLOAD_MB | 50 | 单文件上限 |
| EXAM_GRADER_TIMEOUT | 90 | 单个评分器超时秒数 |
| EXAM_MAX_PARALLEL | 2 | 同时判分人数 |
| EXAM_UPLOAD_TTL | 6 | 临时文件保留小时数 |
| EXAM_SECRET_KEY | 随机 | 固定下来可避免重启后 session 失效 |
| EXAM_JANITOR | 1 | wsgi 下是否启动清理线程 |

## 本地回归

```
python tools/selftest.py          # 所有评分器对标准答案跑一遍，应全 100
python tools/core_sweep.py        # 核心库能否解析全部答案文件
```

第 1 套 Word 没有答案文件，selftest 会提示"答案文件不存在"，属正常。
