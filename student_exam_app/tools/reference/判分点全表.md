# Office 操作题判分点全表

按 ECMA-376 梳理，覆盖题库已考 + 未考但可能出现的考点。
每行三列：元素、语义、判定要点与陷阱。写评分器前先查这里，别凭印象。

## 一、Word（WordprocessingML, §17）
### 文档与节

| 元素/属性 | 语义 | 判定要点 / 陷阱 |
| --- | --- | --- |
| `w:pgSz@w/h/orient` | 纸张大小方向 | A4=11906×16838 twips；横向看 `orient="landscape"`（宽高会互换，别只比 w） |
| `w:pgMar@top/right/bottom/left/header/footer/gutter` | 页边距 | 2.8 厘米=1588、3 厘米=1701；`header/footer` 是页眉页脚距边界，不是边距 |
| `w:pgBorders` + 四条 `w:top…` | 页面边框 | `offsetFrom="page"` 是页面边框，`text` 是文字边框；艺术型看 `w:val` |
| `w:cols@num/space/sep/equalWidth` | 分栏 | 多节文档要按 `sectPr` 逐节取；`w:cols` 出现在 `sectPr` 里，不在 pPr |
| `w:docGrid@type/linePitch/charSpace` | 文档网格 | "每页 42 行每行 39 字" = `type="linesAndChars" linePitch=… charSpace=…` |
| `w:pgNumType@fmt/start` | 页码格式/起始 | 起始页 1 = `start="1"`；罗马数字看 `fmt="lowerRoman"` |
| `w:titlePg` | 首页不同 | 必须配合 `headerReference@type="first"` 才生效 |
| `w:evenAndOddHeaders`（settings） | 奇偶页不同 | 在 settings.xml，不在 document.xml；缺它则 even 页眉不生效 |
| `w:sectType@val` | 分节符类型 | `nextPage`/`continuous`/`evenPage`/`oddPage` |

### 段落与字符

| 元素/属性 | 语义 | 判定要点 / 陷阱 |
| --- | --- | --- |
| `w:pStyle@val` | 段落样式 | 样式名是 styleId，中文名在同 id 的 `w:name`；"标题 1" 的 id 常是 `1` |
| `w:jc@val` | 对齐 | 两端对齐=`both`，分散对齐=`distribute`；不要拿 `center` 一把梭 |
| `w:ind@firstLine/firstLineChars/left/right/hanging` | 缩进 | `firstLineChars="200"` 是 2 字符；混用 twips 与字符单位会差 100 倍 |
| `w:spacing@before/after/line/lineRule` | 段前段后/行距 | 固定值 18 磅 = `line="360" lineRule="exact"`；倍数行距是 `lineRule="auto"` + `line="240"×倍数` |
| `w:snapToGrid` | 对齐网格 | 关闭才允许非整数行距，题干说"固定值"时答案常关它 |
| `w:keepNext/keepLines/pageBreakBefore/widowControl` | 分页控制 | 常见"标题不与正文分离"=`keepNext` |
| `w:outlineLvl@val` | 大纲级别 | 0=1 级；目录靠它抓取，样式标题也自带 |
| `w:numPr`→`w:num`→`w:abstractNumId` | 编号 | 段落必须真引用 numId；只建 abstractNum 不算 |
| `w:pBdr` / `w:shd` | 段落边框底纹 | `w:shd@val` 是图案（clear/solid），`@fill` 才是颜色 |
| `w:framePr@dropCap/lines/h/wrap` | 首字下沉/文本框 | `dropCap="drop"` + `lines="2"`；文本框也用它定位 |
| `w:rFonts@ascii/hAnsi/eastAsia/cs` | 字体 | 中文看 `eastAsia`，西文 `ascii`；只判 ascii 会漏"华文行楷" |
| `w:b/@bCs` `w:i/@iCs` | 加粗/斜体 | `w:b w:val="0"` 是**取消**加粗，别只看标签存在 |
| `w:sz@val` `w:szCs` | 字号 | 半磅单位：二号=44（22 磅），小四=24；中文复杂文种看 szCs |
| `w:color@val/themeColor/themeTint` | 颜色 | 主题色要看 `themeColor` + `themeTint`，`val="auto"` 是自动 |
| `w:u@val` | 下划线 | 单线=`single`，波浪=`wave`，"始终无下划线"是链接样式不是 u |
| `w:vertAlign@val` | 上下标 | `superscript`/`subscript`，不是 position |
| `w:spacing@val`（rPr 内） | 字符间距加宽 | 单位 twips，加宽 2 磅 = `val="40"` |
| `w:em@val` / `w:highlight@val` | 着重号 / 突出显示 | 着重号是 em，不是下划线 |

### 表格

| 元素/属性 | 语义 | 判定要点 / 陷阱 |
| --- | --- | --- |
| `w:tblW@w/type` | 表宽 | `type="pct"` 是百分比（5000=100%），`dxa` 是 twips |
| `w:jc@val`（tblPr 内） | 表格对齐 | `center`；与内容居中无关 |
| `w:tblBorders` / `w:tcBorders` | 边框 | 单元格级覆盖表级；"外框双线内框单线"要分别判 top/insideH |
| `w:tblLayout@type` | 固定/自动布局 | "根据内容调整"=`autofit` |
| `w:tblCellMar` / `w:tblCellSpacing` | 单元格边距/间距 | 单位 twips |
| `w:tblStyle@val` + `w:tblLook` | 表格样式 | 样式 id 与显示名不同；套用后局部底纹会覆盖 |
| `w:trHeight@val/@hRule` | 行高 | 1 厘米=567；`hRule="exact"` 是固定值 |
| `w:gridSpan` / `w:vMerge` | 合并单元格 | 横向 gridSpan，纵向 vMerge(restart/continue)；没有 mergeCell 概念 |
| `w:tcW` / `w:shd` / `w:vAlign` | 列宽/底纹/垂直对齐 | `shd@fill` 颜色，`vAlign="center"` |
| `w:tblHeader` | 标题行重复 | 跨页表头 |

### 域、引用、批注

| 元素/属性 | 语义 | 判定要点 / 陷阱 |
| --- | --- | --- |
| `w:fldSimple@w:instr` / `w:instrText` | 域代码 | 页码 `PAGE`、总页 `NUMPAGES`、日期 `DATE`、目录 `TOC`、题注 `SEQ`、邮件合并 `MERGEFIELD`、交叉引用 `REF` |
| `w:fldChar@type` | 复合域分界 | begin/separate/end 三段，缓存结果在中间段 — 判"是不是域"看 instrText，判"显示什么"看缓存文本 |
| `w:bookmarkStart/@w:name` | 书签 | 交叉引用/目录跳转依赖它 |
| `w:hyperlink@r:id/@w:anchor` | 超链接 | 外链看 r:id→rels 的 Target；站内锚点看 `w:anchor` |
| `w:footnoteReference` + `footnotes.xml` | 脚注 | 编号在 `w:footnote@w:id`；尾注同理 endnotes |
| `w:commentReference` + `comments.xml` | 批注 | 批注正文独立部件 |
| `w:ins` / `w:del` / `w:rPrChange` | 修订 | 修订未接受时文字在 `w:ins` 里，`w:delText` 是被删内容 |
| `w:sdt` + `w:sdtPr` | 内容控件 | 下拉/日期控件：`w:dropDownList`、`w:date`；题干"控件"类考点 |

### 图形、图表、其他

| 元素/属性 | 语义 | 判定要点 / 陷阱 |
| --- | --- | --- |
| `w:drawing/wp:inline|wp:anchor` | 图片/图形容器 | inline=嵌入型；anchor 带 `behindDoc`、`wrap*`、`distT/B` |
| `wp:extent@cx/cy` | 尺寸 | EMU，1 厘米=360000；7 厘米=2520000 |
| `a:blip@r:embed` | 图片引用 | 指向 rels 里的 media 文件 |
| `a:srcRect@l/t/r/b` | 裁剪 | 千分比；`l="25000"` 裁掉左侧 25% |
| `a:lum@bright/contrast` | 亮度对比度 | 百分比 ×1000 |
| `a:prstGeom@prst` | 形状类型 | rect/roundRect/ellipse/rightArrow… |
| `a:prstTxWarp@prst` | 艺术字变形 | textArchUp 等 |
| `w:pict/v:shape/v:imagedata` | VML 旧式图形 | 剪贴画、水印、老模板；`v:textpath@string` 是艺术字文字 |
| `w:drawing` 里 `c:chart@r:id` | 图表 | 图表数据在 `word/charts/chartN.xml`，不在 document.xml |
| `dgm:relIds` | SmartArt | 内容在 `word/diagrams/dataN.xml` |
| `m:oMath` | 公式 | math 命名空间；老版公式是 `EQ` 域 |
| `w:settings` 里 `w:documentProtection` | 文档保护 | 只读/仅表单 |
| `w:mailMerge` | 邮件合并 | 见上文专章 |

## 二、Excel（SpreadsheetML, §18）
### 工作簿与工作表

| 元素/属性 | 语义 | 判定要点 / 陷阱 |
| --- | --- | --- |
| `workbook.xml/sheets/sheet@name/sheetId/state` | 表名与隐藏 | 改名判 `name`；`state="hidden"/"veryHidden"` 是隐藏表 |
| `xl/_rels/workbook.xml.rels` | 表→文件映射 | sheetId ≠ sheetN.xml，必须走 rels（老陷阱） |
| `sheetPr/sheetPr/tabColor@rgb/theme` | 工作表标签颜色 | "蓝色"可能是主题色 acc1，不是 rgb |
| `sheetPr/outlinePr`、`pageSetUpPr` | 分级/打印设置 | `summaryBelow`、`fitToPage` |
| `sheetViews/pane` | 冻结窗格 | `state="frozen"` + `xSplit/ySplit/topLeftCell` |
| `cols/col@width/customWidth/bestFit` | 列宽 | "自动调整列宽"= `bestFit="1"`；宽度单位是字符数 |
| `row@ht/customHeight/hidden/outlineLevel` | 行高/隐藏/分级 | 分类汇总的分级在行上；隐藏行用于筛选判定 |
| `mergeCells/mergeCell@ref` | 合并单元格 | 与"跨列居中"（centerContinuous）不同 |
| `autoFilter@ref` + `filterColumn` | 自动筛选 | 结果行 `hidden="1"`；高级筛选另有条件区 + `_FilterDatabase` 名称 |
| `sortState/sortCondition@ref/descending` | 排序 | 直接子节点；两列排序看 sortCondition 顺序 |
| `dataValidations/dataValidation@type/sqref` | 数据有效性 | 序列看 `formula1`；圈释无效数据在 `x14` |
| `conditionalFormatting@sqref` + `cfRule` | 条件格式 | 范围看 sqref；`dxfId` 指向样式表 dxfs |
| `hyperlinks` / `hyperlinks/hyperlink@ref` | 单元格超链接 | `r:id` 指向外部链接 rels |
| `printOptions@horizontalCentered/verticalCentered` | 打印居中 | 页面设置类考点 |
| `pageMargins@left/right/top/bottom/header/footer` | 页边距 | 单位英寸！1 厘米≈0.3937，别按 twips 判 |
| `pageSetup@paperSize/orientation/scale/fitToWidth/firstPageNumber` | 纸张缩放 | A4=9；横向 `orientation="landscape"` |
| `headerFooter/oddHeader/oddFooter` | 页眉页脚 | `&amp;L &amp;C &amp;R` 分段，`&amp;P` 页码，`&amp;N` 总页 |
| `definedNames/definedName@name` | 定义名称 | 打印标题 `_xlnm.Print_Titles`，打印区域 `_xlnm.Print_Area` |
| `sheetProtection@sheet/password` | 保护工作表 | 密码是哈希，判"是否保护"只看属性 |

### 样式与数字格式

| 元素/属性 | 语义 | 判定要点 / 陷阱 |
| --- | --- | --- |
| `numFmts/numFmt@numFmtId/formatCode` | 自定义数字格式 | 内置格式用 id（14=日期，4=#,##0.00） |
| `fonts/font@sz/name/b/i/color/u` | 字体 | 主题字体 `theme="1"` 要查 theme1.xml |
| `fills/fill@patternFill@fgColor/bgColor` | 填充 | 纯色在 fgColor；`patternType="solid"` 时 bgColor 无效 |
| `borders/border@top/left/bottom/right/diagonal` | 边框 | style 值 thin/medium/thick/double；颜色看 color@rgb |
| `cellXfs/xf@numFmtId/fontId/fillId/borderId/alignment` | 单元格格式索引 | `applyNumberFormat/applyFont…` 决定是否生效 |
| `alignment@horizontal/vertical/wrapText/textRotation/indent` | 对齐 | centerContinuous=跨列居中；shrinkToFit 缩排填充 |
| `dxfs/dxf` | 条件格式样式 | 条件格式的颜色在这里，不在 cellXfs |
| `tableStyles` | 表格样式 | 表用 `tableStyleInfo@name`（中文名） |
| 单元格 `t="s"/t="inlineStr"/t="str"` | 单元格类型 | 文本走 sharedStrings；`t="str"` 是公式结果字符串 |
| 单元格 `f` / `v` / `is` | 公式/值/富文本 | 判公式看 `f`，判结果看 `v`（缓存值可能过期，重算后为准） |

### 表、透视、图表、扩展

| 元素/属性 | 语义 | 判定要点 / 陷阱 |
| --- | --- | --- |
| `tableParts` + `tables/table1.xml` | 智能表 | `tableColumns` 是列名；`tableStyleInfo@showRowStripes` |
| `pivotTableDefinition` + `pivotCacheDefinition` | 数据透视表 | 字段名在 cacheField；行/列区看 `pivotField@axis`，值区看 `dataField@name/subtotal` |
| `xl/charts/chart1.xml` | 图表 | `c:barChart`/`c:bar3DChart`/`c:lineChart`/`c:pieChart`；标题在 `c:title/c:tx/c:rich/a:t`；图例 `c:legendPos` |
| `xdr:twoCellAnchor`（drawing1.xml） | 图表/图形位置 | from/to 行列反推区域，如 A18:G30 |
| `x14:dataBar`（extLst） | Excel 2010 数据条 | 渐变/实心、边框都在 x14，基础 dataBar 只是壳 |
| `x14:sparklineGroups` | 迷你图 | `x14:sparkline@f` 数据范围，`sqref` 放置位置 |
| `x14:conditionalFormattings` | 扩展条件格式 | 图标集、按值着色等 2010 新特性 |
| `legacyDrawing` + `vmlDrawing` | 批注/表单控件 | 批注形状在 vmlDrawing1.vml |
| `comments1.xml` | 批注文本 | 与 vml 形状配合 |
| `x14:slicerList` | 切片器 | 数据透视/表筛选器 |
| `calcPr@fullCalcOnLoad` | 打开时重算 | 判"公式是否有缓存值"时相关 |

## 三、PPT（PresentationML §19 + DrawingML §21）
### 演示文稿与幻灯片

| 元素/属性 | 语义 | 判定要点 / 陷阱 |
| --- | --- | --- |
| `p:sldMasterIdLst` / `p:sldIdLst` | 母版/幻灯片列表 | 顺序以 sldIdLst 为准；`p:sldId@id` 是内部 id |
| `p:sldSz@cx/cy` | 幻灯片尺寸 | 16:9 = 12192000×6858000 EMU；4:3 = 9144000×6858000 |
| `p:notesSz` | 备注页尺寸 | 与幻灯片尺寸分开 |
| `p:defaultTextStyle` | 默认文本样式 | 新建文本框继承它 |
| `p:sectLst`（p14） | 节 | 2010 的节在扩展命名空间 |
| `p:sldId@show="0"` | 隐藏幻灯片 | 放映时跳过 |
| `p:cSld@name` | 幻灯片名称 | 大纲视图里的名字 |

### 形状与文本

| 元素/属性 | 语义 | 判定要点 / 陷阱 |
| --- | --- | --- |
| `p:sp` / `p:pic` / `p:graphicFrame` / `p:grpSp` / `p:cxnSp` | 形状种类 | 图片是 pic、表格图表是 graphicFrame、组合是 grpSp |
| `p:nvSpPr/p:cNvPr@name/id` | 形状名与 id | 动画按 spid 关联，名字重复会撞 |
| `p:spPr/a:xfrm/a:off|x` / `a:ext@cx/cy` / `@rot` | 位置尺寸旋转 | EMU；`rot` 单位 1/60000 度（90°=5400000） |
| `a:prstGeom@prst` / `a:custGeom` | 预设/自定义形状 | roundRect、ellipse、actionButton*、flowChart* |
| `a:solidFill/a:srgbClr|schemeClr` | 填充 | `schemeClr@val="accent1"` 要查主题 |
| `a:gradFill` + `a:gsLst` | 渐变 | 艺术字常用；判"两种颜色渐变"看 gs 数量 |
| `a:ln@w` + `a:solidFill` | 轮廓 | 宽度 EMU |
| `a:effectLst/a:softEdge@rad` | 柔化边缘 | 题库"柔化边缘矩形" |
| `a:effectLst/a:outerShdw` / `a:glow` | 阴影/发光 | 图片样式类考点 |
| `a:blipFill/a:blip@r:embed` | 图片引用 | media 文件 |
| `a:srcRect` | 裁剪 | 千分比 |
| `p:txBody/a:bodyPr@anchor/wrap/vert/anchorCtr` | 文本框属性 | 垂直居中 `anchor="ctr"`；竖排 `vert="vert270"` |
| `a:pPr@algn/marL/lvl/indent` | 段落 | 居中 `algn="ctr"`；层级 `lvl` |
| `a:buChar@char` / `a:buAutoNum@type` / `a:buNone` | 项目符号/编号 | "1. 2. 3."=`arabicPeriod`；`buNone` 是取消 |
| `a:lnSpc/a:spcPct@val` | 行距 | 100000=1 倍，120000=1.2 倍；`spcPts` 是固定磅值 |
| `a:spcBef` / `a:spcAft` | 段前段后 | `spcPts` 磅或 `spcPct` |
| `a:rPr@sz/b/i/u` + `a:latin/a:ea/a:cs` | 字号字体 | 字号×100；中文在 `a:ea` |
| `a:prstTxWarp@prst` | 艺术字变形 | textArchUp 等 |

### 动画、切换、放映

| 元素/属性 | 语义 | 判定要点 / 陷阱 |
| --- | --- | --- |
